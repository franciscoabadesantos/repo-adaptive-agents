# Research history

This directory records why the product direction changed without placing raw
benchmark material in normal Git history.

The research progressed through three stages:

1. **Knowledge resolution.** Deterministic requirements, capability matching,
   ranking, and coverage were explored. Small development cases could be fit
   well, but the approach did not establish general semantic performance.
2. **Admission control.** Deterministic logic was narrowed to explicit facts:
   identity, lifecycle, scope, compatibility, exposure, controls, conflicts,
   and catalog changes. The first blind evaluation required a substantive
   compatibility adapter, so it did not validate native attribution.
3. **Native boundary.** The final experiment separated external model/retrieval
   relevance from native `admit()` and `validate()` operations. Public evidence
   supports deterministic post-validation and selective withholding where
   exposure itself is restricted.

The resulting product hypothesis is behavioral: will one engineering team
contribute useful knowledge once and reuse it through coding agents? Shared
knowledge v0.1 has not been implemented in this baseline.

## Evidence status

- Aggregate public and pre-gold measurements are recorded here.
- Final human-readable blind-scoring reports are represented by explicit
  placeholders until supplied by the research owner.
- No hidden gold has been reconstructed.
- Raw responses, predictions, authored-gold corpora, and complete evaluation
  trees remain restricted archives outside normal Git history.
